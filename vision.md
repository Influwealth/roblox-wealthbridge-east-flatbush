## Vision
A Roblox world that teaches finance, making, telecom resilience, and civic planning through quests,
wrapped in a 90s East Flatbush theme.

Players earn Community Credits styled like fare cards/punch cards.
Real-world redemption flows are mediated through WealthBridge OS with guardian consent + auditability.

## Tech Notes
- Gateway mediates Roblox -> MCP (no secrets on client)
- Observability: trace events for quest completion + redemption requests
- Optional infra: Google Data Commons, NVIDIA vGPU, and high-throughput linking (as available)
